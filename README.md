## Como abrir

1. Abra a Godot (`/Applications/Godot.app`).
2. Clique em **Importar** e escolha o arquivo `project.godot` desta pasta.
3. Clique em **Importar e Editar** e depois no botão ▶ (canto superior direito) para executar.
4. Clique no chão para mover a esfera.
